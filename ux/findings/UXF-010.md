The names a reader looks up are inline code: the fields of `std.fs` (`path`, `create`,
`flag`), the commands on the diagnostics page, the identifiers of every reference table. In
the book they are 0.86em of the body: 13.3 px at 1440x900 and 11.9 px at 390x844, inside
table cells of 13.9 px. The roadmap's state badges ("released", "unreleased", "design") are
10.0 to 11.9 px. The landing page's code windows and version tags are 12.5 to 13.4 px.

Measured with Playwright on `target/site/` at both gating viewports (computed `font-size` of
every visible text node under 14 px). Sessions: every session that reaches a reference page
or the roadmap.

Cost: M (touches the book's code size and the landing page's windows). One line: raise the
inline-code and badge sizes so their computed size is at least 14 px.

Fix: the book's inline code and badges are `max(<their em size>, 14px)` (`site/book/theme/ignite.css`); the landing page's inline code, code windows, step code and version tags the same, after its media queries (`site/assets/site.css`). Smallest computed size over the test's elements on index, std.fs, roadmap, diagnostics and design at all five viewports: 14.00 px (before 9.98 px, a roadmap badge in a table heading at 390x844).
