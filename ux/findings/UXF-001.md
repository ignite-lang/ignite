A code block or a table wider than its box scrolls sideways, but nothing in it takes focus, so
a keyboard user cannot scroll it and never reads its right-hand side.

Before: 796 axe nodes of `scrollable-region-focusable` over the gating runs (book code blocks
at both viewports, tables and landing-page windows at 390x844), every book page failing.

Fix: `site/book/theme/ignite.js` and `site/assets/site.js` give each `pre`, `pre > code` and
`table` that actually scrolls `tabindex="0"`, again on resize and on a tab switch; one that
does not scroll gets no tab stop.

After: 0 nodes; `pages/<viewport> axe.serious_critical` is 0 in `ux/baseline.json`.
