  v0.16.0 release commits. One pull request into `main` after a green `task gate` and a
  dedicated-host run without a refusal, then the release of `AGENTS.md` § Releases.
- Commits authorised: listed in the approval record.
- Agents: `aep:implementor`, then `aep:adversary` on each unit that reports green (at most two
  passes), model opus, at most two implementors at once.
- Check path: the coordinator wrote each story's scope from six diagnoses
  ([2026-11-11-wave-11-diagnosis/](2026-11-11-wave-11-diagnosis/)); no `aep:story-scoper` ran.
  Entries are typed `cited` where a diagnosis patch touched the file, `inferred` otherwise.
- No timing or benchmark is run on the workstation. A unit proves counts (system calls,
  allocations, bytes, sites, instructions); the dedicated-host run of the release candidate
  decides every timing row.
