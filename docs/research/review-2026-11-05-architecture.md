# Verdict and ranked recommendations

**Verdict.** The crate graph is clean and `Symbols` → `TypedProgram` → consumers is the right shape, but the language's semantics are implemented three times (rustgen text, LLVM IR, evaluator) and its ownership rule five times, each as its own AST walk. `docs/design.md:401-403` already names the missing layer ("Ignite Code IR makes data layout, ownership operations, checked arithmetic, closures … explicit"); vision D7 renamed only the system model. Two exposures are architectural: a Rust panic inside the runtime on an LLVM task thread aborts the process (91 `extern "C"` entries, no `catch_unwind`/`C-unwind`, `crates/ignite-rt/src/lib.rs:34-69`), and saved apply plans identify an implementation by the AST's `Debug` text (`crates/ignite/src/apply/plan.rs:1538-1580`). Scaling is bounded by "nothing cached between CLI spawns" plus a `TypedProgram` keyed by heap addresses (`crates/ignite-types/src/lib.rs:1319-1377`).

## 4 Correctness risks

1. **C ABI panics (V code, I behaviour).** 91 `extern "C"` entries, none `C-unwind`, no `catch_unwind` except `io/src/report.rs:174`, no abort profile. Ignite failures `longjmp` to the task wrapper (`rt/src/fail.rs:111-141`, `lower.rs:4496-4511`), so T1 holds for them; a Rust panic inside the runtime on a task thread unwinds into an `extern "C"` frame → abort (Rust ≥ 1.81), with the report swallowed by the hook (`report.rs:119-147`). `fail.rs:16-18`, `docs/llvm.md:463-465` describe Rust-target behaviour; untested. Null thunks UB (`rt/src/store.rs:95-109`); errors collapsed to 0/empty where no `err` out-param (`rt/net.rs:271-273`, `rt/pipe.rs:73-75`, `rt/process.rs:209-216`); self-opened handles leak on failure (`docs/llvm.md:460`).
2. **Address-keyed `TypedProgram` (V).** 18 tables keyed by `expr as *const Expr as usize` (`types/src/lib.rs:1319-1377`); safe today (no `Program` clone, no synthesised nodes), forbids caching, serialisation and desugaring.
3. **Apply identities from `Debug` (V).** `format!("{decl:?}")` with spans scrubbed by string scan (`apply/plan.rs:1538-1580`), pinned by a hand-bumped `CODEGEN_REVISION` (:15-17); plan ids digest absolute paths and env (:1201-1302, 1453-1469), non-portable by design.
4. **Global state (V).** Substrate singletons shared by tests in one binary: handle table (`rt/net.rs:113-119`), `ARGS`/`atexit`/`SIGPIPE` (`rt/process.rs:22-24,95-118`), worker pool (`io/task.rs:50-141`), `drain::MODE` never cleared (`io/drain.rs:31`), `EXIT_HOOKS` (`io/lib.rs:1017`), panic hook, `SIGCHLD` reset (`io/child.rs:317-327`). Driver: process-wide `sigaction` + static pipe fd (`run/control.rs:305-351`); second install strands the first (I).
5. **Ordering (V).** O30 holds on both journals (`live.rs:517-535`, `host/mod.rs:141-150`, `controller.rs:1103-1118`); timers `(at, seq)` (`engine.rs:556-558`). The manual clock still carries a wall-clock settle and 20 ms grace (`live.rs:1384-1400`, `control.rs:116-131`); journal equality holds only after masking pid/latency (`tests/run.rs:884-965`).
6. **Header vs plan identity (I).** `check_header` compares `sourceMap` (`lib.rs:1443,1480`) while `semantic_model` strips it (`plan.rs:1504`): span-only edits refuse an `ignite run` resume (E126) but keep a plan valid.
7. **Error asymmetries (V/I).** `Model::to_json` round trip is `expect` on host/run threads (`apply/revision.rs:31,73,123`, `controller.rs:1105`) vs exit 3 (`lib.rs:1579`); `receipts.get_mut().unwrap()` (`controller.rs:320`, I); `relay` write errors dropped (`control.rs:278`).
8. **Tests and timing (V).** 35 modules in one binary at `RUST_TEST_THREADS=4`; shared `BUILDS`/`RUST`/`LLVM` mutexes and ten `OnceLock` caches; wall-bounded asserts `run.rs:684-687` (100-500 ms), `drain.rs:565`, `slice17.rs:257,286`, `apply_host.rs:947`, `rfc.rs:842`, `cli.rs:533`, `slice9.rs:268`, `types/tests/limits.rs:44,65,109` (failed under load, slice 15), `rt/tests/pipe.rs:228-233` (50 ms race, I); apply suites on the real clock with a 10 s settle (`revision.rs:174-176`).
9. **`Store.update` under the lock (V).** Re-entrancy prevented only by E017, not the substrate (`io/store.rs:148-150`, `rt/store.rs:201-208`).

## 5 Scaling (V unless marked)

- Nothing cached per CLI spawn: parse program, roots, parse+check reached std, type all, type program (`lib.rs:766-792,585-647,822-832`); inside one apply the program loads four times (`plan.rs:1171,1207`, `revision.rs:25`, `controller.rs:450`); the run build stamp hashes the whole std root (`lib.rs:1312-1315`).
- std growth hits every program importing a kind with hooks: `std.protocol.http` imports `std.control` (2,062 lines), `std.policy`, two catalogues (2,072) (`std/protocol/http.ignite:3-11`); friction 43 measured check 0.068→0.131 s and `ignite-std` 1,049→1,700 lines; 12b: std parse/check/type 13.7/16.2/36.7 ms, `std.control` 21 ms of typing; slices 15-17 each recorded 1.1-1.3 on check/plan.
- Cache blockers: address keys; `Symbols` carries AST `Type`s and `Span`s (`check:451-473`), `Span` has no file id (`ast.rs:6-9`); backends need every std `TypedProgram` (`type_std`, `lib.rs:822`); eval interprets std bodies at check time (`eval/src/lib.rs:51-57`). `ModuleTypes` (`types:765-794`) is already the cacheable interface.
- Gate: cold 605→664 s, warm 450→517 s at slice 16; the end-to-end binary is 493 of 547 s, set by the apply suites and cargo builds inside tests. `crates/ignite/build.rs:13-68` compiles `ignite-rt`+`ignite-io` a second time into its own target dir with `rerun-if-changed` on both (share of the 2.2-4.0 s `--no-run after touch` rows unmeasured, I).
- `ignite-std` per program: regenerated and recompiled per `--target rust` build (`lib.rs:1784-1796`); slice 11 split todod dev as io 2.37 s, std 0.37 s, program 0.26 s of 3.19 s, so the substrate from source is the Rust floor, not the generated std. LLVM: reachable-only `std.ll`, `clang -O2` 0.48 s; the 0.31 vs 4.0 s dev ratio rests on the C ABI path of risk 1.
- One integration binary: good link time, but statics and mutexes serialise and the wall is the longest module.
- Runtime: thread per task, no `stack_size` set (grep both crates); LLVM reads allocate `maximum` zeroed bytes per read (`rt/net.rs:309-323`, malloc above 16 KiB, `arena.rs:190-238`, untrimmable `arena.rs:397-403`) (cost I); global lock on handle register/release (`rt/net.rs:192,420`); `waited` lists grow for the process life (`rt/net.rs:92-100,389-397`).

Not recommended: `panic = "abort"` for `ignite-rt` (drops the T1 promise); a shared `CARGO_TARGET_DIR` for program builds (claims already cover it).
